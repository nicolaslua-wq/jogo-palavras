# Jogo de Adivinhação de Palavras

Projeto desenvolvido na disciplina de Desenvolvimento de Aplicações Web I (IFPB - Campus Campina Grande).

## Integrantes
- Nicolas Lua

## Como jogar
Digite uma letra e clique em **Tentar** (ou pressione **Enter**). O objetivo é descobrir a palavra secreta antes de acabar as 6 tentativas.

## Tecnologias
- HTML5
- CSS3
- JavaScript

## Funcionalidades
- Escolha aleatória de palavras
- Controle de tentativas restantes
- Histórico de letras utilizadas e bloqueio de repetição
- Envio de letra usando a tecla Enter
- Reinício rápido da partida
